## Features

| Name | Description |
|------|-------------|
| Unified API Endpoint | Access Microsoft 365 data through a single REST endpoint at graph.microsoft.com. |
| Real-Time Notifications | Subscribe to change notifications via webhooks for real-time updates. |
| Batch Requests | Combine multiple API requests into a single HTTP call. |
| Delta Queries | Track incremental changes to resources efficiently using delta links. |
| Rich Mail Management | Read, send, reply, forward, and organize email messages. |
| Calendar and Scheduling | Create events, manage calendars, check free/busy availability. |
| File Storage and Sharing | Access OneDrive and SharePoint files with collaboration capabilities. |
| Team Collaboration | Manage Microsoft Teams channels, messages, tabs, and apps. |
| User and Group Management | Create, update, and manage users, groups, and directory resources. |
